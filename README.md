Άσκηση 4:
Στην άσκηση 4 συνδυάζω ταξινομημένη λίστα και map ώστε να έχουμε τη σειρά των στοιχείων και τη γρήγορη αναζήτηση αντίστοιχα

omap_set_destroy_key():έχει πολυπλοκότητα Ο(1) 
omap_set_destroy_value():έχει πολυπλοκότητα Ο(1) 
omap_destroy(): έχει πολυπλοκότητα Ο(n) αφού καταστρέφονται όλα τα στοιχεία της λίστας και στη συνέχεια του map
omap_first(): έχει πολυπλοκότητα O(1) επειδή στην ταξινομημένη λίστα το πρώτο στοιχείο είναι και το μικρότερο
omap_last():έχει πολυπλοκότητα O(1) επειδή στην ταξινομημένη λίστα το τελευταίο στοιχείο είναι και το μεγαλύτερο
omap_next(): έχει πολυπλοκότητα O(n) επειδή γίνεται αναζήτηση για το key που δόθηκε και μετά για το επόμενο
omap_previous(): έχει πολυπλοκότητα O(n) επειδή γίνεται αναζήτηση για το key δόθηκε και μετά για το προηγούμενο
omap_find_node(): έχει πολυπλοκότητα Ο(1) αφού βρίσκουμε το ListNode μέσω του map απευθείας
omap_node_key(): έχει πολυπλοκότητα Ο(1) αφού επριστρέφεται το key 
omap_node_value(): έχει πολυπλοκότητα Ο(1) αφού επριστρέφεται το value
